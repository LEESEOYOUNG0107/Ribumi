# Ribumi

리부미(Ribumi)는 다양한 문화 콘텐츠의 원작과 각색작의 관계를 탐색할 수 있는 웹 서비스입니다.

사용자는 영화, 드라마, 뮤지컬, 연극, 도서 등 다양한 작품 정보를 확인하고, 작품 간의 연결 관계를 통해 원작과 관련 작품을 한눈에 살펴볼 수 있습니다.

## 주요기능
- 작품 검색
- 작품 상세 정보 조회
- 원작 및 각색작 탐색
- 관련 작품 추천

## Tech Stack
- React
- JavaScript
- Supabase
- TMDB Open API
- 알라딘 Open API
- KOPIS Open API
